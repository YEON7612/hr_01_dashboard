# 06_sql

각 질문(q-001~008)의 핵심 집계를 재현할 수 있는 SQL 쿼리를 보관하는 폴더입니다. 원본 CSV(`data/HR_직원.csv`, `HR_퇴사이력.csv`, `HR_평가.csv`, `HR_근태.csv`)를 각각 같은 이름의 테이블로 적재했다고 가정합니다.

- 문법은 BigQuery/PostgreSQL 계열을 기준으로 작성했습니다(`DATE_DIFF`, `STDDEV`, `EXTRACT` 등). 실제 사용하는 엔진에 따라 함수명·인자 순서를 조정해야 할 수 있습니다.
- 로지스틱 회귀(q-005), t-검정(q-004), 피어슨 상관계수(q-006) 같은 통계 검정·모델 학습 자체는 SQL이 아니라 Python(pandas/scipy/scikit-learn)에서 수행되었습니다. 여기 있는 쿼리는 그 입력이 되는 집계·피처 테이블까지를 재현합니다.
