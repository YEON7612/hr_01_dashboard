# 분석 방법

`raw/HR_근태.csv`(3,600건)를 부서·분기 단위로 평균·표준편차를 집계하고, 같은 시기 구간에 대해 `raw/HR_퇴사이력.csv`의 사유 비중 변화를 나란히 비교했다.

## 한계

- **상관관계-인과관계 혼동 위험**: 부서 평균 초과근무 1위(영업)와 부서 퇴사율 1위(개발)가 서로 다르다는 결과는 두 지표가 부서 단위에서 단순 대응하지 않는다는 뜻일 뿐이다. 이는 집단(부서) 단위 평균끼리의 비교이므로, 개별 직원이 초과근무 때문에 퇴사했는지/하지 않았는지는 이 분석으로 알 수 없다(생태학적 오류 위험 — 집단 수준 상관을 개인 수준 인과로 확대 해석하면 안 됨).
- **테이블 재현성 문제**: [[부서별_근태현황]]은 "부서별 평균(h)" 1개 값으로, [[퇴사사유_강조_부서별_초과근무_추이]]는 "분기별 4개 값"으로 같은 원본 데이터를 서로 다른 집계 단위로 제시한다. 두 표를 나란히 놓고 재현하려면 집계 기준(연평균 vs 분기별)을 먼저 통일해야 하며, 그렇지 않으면 같은 수치를 두 번 다르게 인용하는 것처럼 보일 수 있다.
- **표본 임계값 미달로 제외된 세그먼트**: 없음 — 근태 데이터는 3,600건으로 대규모라 이 분석 자체에서 표본 부족 문제는 발생하지 않는다.
