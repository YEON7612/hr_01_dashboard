# HR 데이터 정제규칙 (근태 / 직원 / 퇴사이력 / 평가)

적용 대상: HR_직원.csv, HR_근태.csv, HR_퇴사이력.csv, HR_평가.csv
작성 기준일: 2026-08-01 (지금까지 실제로 발견된 이슈 반영)

---

## 1. 인코딩 규칙 (최우선 체크)

**배경**: HR_직원.csv를 재업로드했을 때 UTF-8/EUC-KR(cp949)이 섞여 부서·직급·재직상태 텍스트가 깨진 사례가 있었음.

- 파일을 열 때 항상 `utf-8-sig`로 우선 시도
- 실패하거나 한글이 깨져 보이면(`?`, 물음표, 이상한 문자 조합) 즉시 중단하고 원인 확인 — 계산으로 넘어가지 않음
- 파일을 저장/재업로드할 때는 **UTF-8(BOM 포함)로 통일**해서 저장 (엑셀에서 저장 시 "CSV UTF-8" 옵션 사용)
- 컬럼을 추가한 후 재업로드하는 경우, 반드시 전체 파일을 한 인코딩으로 다시 저장했는지 확인

## 2. 키 값(사번) 검증

- 형식: `E` + 4자리 숫자 (예: E0001) — 이 형식을 벗어나면 오류로 처리
- HR_직원.csv의 사번은 유일해야 함 (중복 시 마스터 데이터 오류)
- HR_근태/HR_평가는 사번이 여러 번 나오는 게 정상(월별/분기별 반복) — 중복 자체를 오류로 보지 않음
- 조인 전, 각 파일의 사번이 HR_직원.csv에 존재하는 사번 집합의 부분집합인지 확인 (없는 사번이 있으면 데이터 오류)

## 3. 날짜/기간 형식 통일

| 파일 | 컬럼 | 형식 | 규칙 |
|---|---|---|---|
| HR_직원 | 입사일 | YYYY-MM-DD | 날짜형 변환 실패 시 오류 처리 |
| HR_퇴사이력 | 퇴사일 | YYYY-MM-DD | 동일 |
| HR_근태 | 년월 | YYYY-MM | `PeriodIndex(freq='M')` 변환 가능해야 함 |
| HR_평가 | 분기 | YYYYQ# | `PeriodIndex(freq='Q')` 변환 가능해야 함 |

- 입사일 > 퇴사일인 경우(논리 오류) 즉시 플래그
- 퇴사일이 오늘(분석 시점) 이후인 경우 플래그

## 4. 범주형 값 허용 목록 (화이트리스트)

새로운 값이 나오면 오타/신규 카테고리 여부를 먼저 확인하고, 확인 전까지는 집계에서 제외.

| 컬럼 | 허용값 |
|---|---|
| 부서 | CS, 개발, 생산, 영업, 인사, 재무 |
| 직급 | 과장, 대리, 부장, 사원, 차장 |
| 재직상태 | 재직, 퇴사 |
| 채용경로 | 공채, 수시, 추천, 헤드헌팅 |
| 평가등급 | S, A, B, C, D |
| 퇴사사유 | 개인사유, 건강, 계약만료, 이직, 이직(경쟁사) |

## 5. 결측치 규칙

- 사번/부서/직급/입사일/재직상태/채용경로/년월/분기/평가등급/퇴사일/퇴사사유: **결측 허용 안 함** (현재까지는 결측 없음 — 향후 결측 발생 시 원인 확인 전까지 해당 행 집계 제외)
- 향후 컬럼이 추가되어 결측이 생기면, "구조상 당연한 결측"(예: 재직자는 퇴사일 없음)인지 "데이터 누락"인지 구분해서 처리

## 6. 논리적 정합성 규칙 (파일 간 교차검증)

- `재직상태='퇴사'`인 모든 사번은 HR_퇴사이력에 반드시 존재해야 함 (현재는 일치함 — 불일치 발생 시 데이터 오류로 처리)
- HR_퇴사이력에 있는 사번은 모두 `재직상태='퇴사'`여야 함 (역방향도 확인)
- 근태/평가 데이터의 년월·분기가 사번의 입사일보다 이전이면 오류 (입사 전 데이터가 있을 수 없음)
  - **2026-08-01 점검 결과**: 12명 사번에서 입사 전 근태/평가 데이터 발견 — E0011, E0028, E0063, E0066, E0071, E0072, E0110, E0112, E0127, E0134, E0158, E0247 (모두 2025년 중 입사했으나 근태·평가는 2025-01/2025Q1부터 존재). HR_근태·HR_평가가 연도 단위로 일괄 생성되면서 입사 전 구간까지 채워진 것으로 추정. 집계 시 해당 사번의 입사 전 행은 제외 처리 필요.

## 7. 이상값(Outlier) 체크 규칙

- **초과근무시간**: 전체 분포 확인 후, 한 사번이 지속적으로(예: 12개월 내내) 평균 대비 3배 이상 높은 값을 보이면 별도 플래그 (삭제하지 않고 "확인 필요" 목록으로 분리)
  - **2026-08-01 점검 결과** (전체 평균 15.4시간, 기준 3배=46.2시간 이상 지속): 9명 해당
    - E0019 (53.2~66.1시간), E0040 (42.3~51.8시간), E0137 (61.2~76.7시간), E0167 (52.1~64.6시간), E0181 (53.2~63.5시간), E0199 (46.4~56.8시간), E0238 (44.7~59.8시간), E0252 (38.5~53.2시간), E0280 (43.5~63.6시간)
- 음수 값, 비정상적으로 큰 값(예: 월 200시간 이상)은 입력 오류로 간주하고 별도 확인

## 8. 중복행 규칙

- HR_직원: 행 전체 중복 시 오류 (사번 유일해야 함)
- HR_근태/HR_평가: 같은 사번+같은 년월(또는 분기) 조합이 2번 이상이면 오류 (같은 기간에 값이 2개 존재할 수 없음)
- HR_퇴사이력: 같은 사번이 2번 이상 나오면 오류 (한 번만 퇴사 가능)

## 9. 파일 업로드/재업로드 시 체크리스트

새 파일을 받을 때마다 아래 순서로 확인 (계산은 이 체크 이후에):
1. 인코딩 정상 여부 (1번 규칙)
2. 행수/열수가 기대한 범위인지 (급격한 변화 시 원인 확인)
3. 신규 컬럼 유무 확인
4. 범주형 값이 화이트리스트를 벗어나는지 확인
5. 키 값(사번) 형식 및 중복 확인
6. 파일 간 정합성(6번 규칙) 재확인
