# 2026-08-29 — Day5 자기도메인: 명세 확정 + 퍼널 실측

**오늘 한 것**

`나의_성장퍼널.md`(4일치 기록)를 근거로 `내도메인.md` 명세 5행을 확정했다. 데이터(4개 CSV, 300명, 사번 그레인), 근속 생존 퍼널(입사→1/3/5/10년), 주지표(초과근무 상위 구간 입사 1년 내 이탈률)와 유지·이탈의 조작적 정의(재직상태 이벤트 기반)까지는 확정했고, 가드레일 기준값과 주지표 경고·위험선은 미정으로 명시했다(다음 회차 과제). 4개 CSV를 실제로 로드해 Kaplan-Meier 생존추정으로 근속 생존 퍼널을 계산하고(1년 97.3%→10년 87.5% 생존), 성장퍼널 로그의 부서·채용경로·초과근무 세그먼트 분해를 오늘 날짜 기준(코호트 전원 결과 확정, n=300)으로 재검증했다.

**고정**

우측절단 편향을 피하려면 스냅샷 코호트 대신 Kaplan-Meier처럼 관측 시점을 명시적으로 다루는 방법을 써야 한다. 명세의 빈 칸(가드레일 기준값, 임계값)은 채우지 못했다고 넘어가지 않고 "미정"이라고 명시하는 것 자체가 오늘의 판정 기준이었다.

**결과**

| 구간 | 생존율 |
|---|---|
| 입사→1년 | 97.3% |
| 1~3년 | 92.4% |
| 3~5년 | 91.1% |
| 5~10년 | 87.5% |

주지표(초과근무 상위 1/3, n=100) 입사 1년 내 이탈률 4.0% vs 하위 1/3(n=100) 1.0%. 부서별로는 개발(5.8%)이 최고. 채용경로 추천·헤드헌팅은 n<30이라 0%를 신뢰하지 않음.

**남은 것**

- 가드레일(업무성과/평가등급) 기준값 확정
- 주지표 경고선·위험선 확정
- 초과근무↔이탈의 인과 여부는 검증 불가(A/B 실험 이력 없음) — 상관관계로만 제시
