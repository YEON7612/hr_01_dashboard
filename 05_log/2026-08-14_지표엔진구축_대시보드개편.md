# 오늘 한 일

> ⚠️ 이 로그는 7/25 이후 약 3주간 밀려 있던 작업을 소급 정리한 것입니다. 실제 작업일과 순서는 커밋 이력과 다를 수 있어, 세부 날짜가 중요하다면 직접 확인 부탁드립니다.

- **지표 엔진 프레임워크 신규 구축**: `calc_metrics.py` + `_INDEX.md`로 지표 계산 엔진 골격을 만듦. 총 10개 지표를 정의했고, 이 중 8개는 확정(finalized), 2개(`overtime_increase_rate_3m`, `high_overtime_employee_rate`)는 데이터가 충분치 않아 검증 불가로 판정 → 선행지표 전용으로 플래그 처리하고 정식 리포팅 대상에서는 제외함.
- **지표 정의서·데이터 조인 규칙 문서화**: `지표정의서.md`, `데이터_조인_규칙서.md` 작성. 다만 정의서에 언급된 `retention_target_rate`, `top_leave_reason` 두 지표는 아직 엔진(`calc_metrics.py`)에 대응하는 `formula_type`이 구현되지 않은 상태로 남아 있음 — 다음 작업에서 이어서 처리 필요.
- **개별 지표 근거 문서 작성**: `avg_overtime.md`, `vacancy_gap_days.md`, `high_overtime_employee_rate.md`, `overtime_increase_rate_3m.md` 등 지표별 산출 근거를 정리. 인사이트/질문 문서 2건(`q-XXX-퇴사-손실-및-선행지표.md`, `i-XXX-초과근무-선행지표-검증불가.md`, `i-XXX-퇴사공석기간-손실규모.md`)도 함께 추가.
- **신규 데이터 반영**: 2026년 1분기 근태 데이터(`HR_근태_2026_1분기.csv`)를 추가하고, 기존 `data/HR_근태.csv`를 갱신.
- **대시보드 UI 개편** (최신 커밋 반영): 다크모드, 라이브/스냅샷 배지, 채용경로별 탭, 목표 달성 배지를 `app.py`에 추가.
- **구버전 자료 정리**: `07_참고자료/` 아래 오래된 파일 3종과 `charts/06_plotly_산점도.py`를 삭제 처리(스테이징까지만 되어 있고 커밋은 아직 안 됨).
- **설정 추가**: `.claude/`, `.mcp.json` 신규 생성.

## 미해결 / 확인 필요

- `retention_target_rate`의 목표값 90%가 어디서 나온 수치인지 출처가 불명확함 (README.md에 "확인 필요"로 표시되어 있음) — 근거 확인 필요.
- `retention_target_rate`, `top_leave_reason` 두 지표는 정의서에는 있지만 엔진에는 아직 구현되지 않음.
- 위 작업들이 아직 커밋되지 않은 상태(워킹트리에 modified/untracked로 남아 있음) — 별도로 커밋 정리 예정.
